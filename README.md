# Многопоточный TCP-сервер на C++

Клиент-серверное приложение на сокетах POSIX: сервер принимает несколько клиентов одновременно, каждого обрабатывает в отдельном потоке, хранит историю сообщений и сохраняет ее на диск при завершении работы.

## Что реализовано

**Сервер (`server.cpp`)**
- слушает порт 5050 и на каждого клиента создает отдельный поток (`pthread`)
- общая история сообщений защищена мьютексом (`pthread_mutex`)
- история загружается из `chat_history.txt` при старте и сохраняется при остановке
- не дает запустить себя дважды: блокировка файла через `flock`
- корректно завершается по `Ctrl+C` / `SIGTERM`: закрывает сокет, сохраняет историю, снимает блокировку
- надежная отправка и прием: дочитывает и дописывает данные частями, повторяет системные вызовы, прерванные сигналом (`EINTR`)

**Протокол.** Каждое сообщение передается с 4-байтным заголовком длины в сетевом порядке байт (`htonl`), поэтому сообщения не склеиваются и не разрываются на границах TCP-пакетов.

**Клиент (`client.cpp`)** подключается к серверу и отправляет команды:

| Команда | Ответ сервера |
|---|---|
| `ping` | `pong` |
| `history` | вся история сообщений |
| `quit` | подтверждение и отключение |
| любой текст | `ECHO: <текст>` |

## Пример

```
$ ./client
Connected to server 127.0.0.1:5050
Commands: ping, history, quit, or any text
> ping
pong
> hello
ECHO: hello
> history
--- History ---
CLIENT(127.0.0.1): ping
CLIENT(127.0.0.1): hello
CLIENT(127.0.0.1): history
----------------
> quit
Server confirmed quit
```

## Сборка и запуск

Работает на Linux и macOS.

```bash
mkdir build && cd build
cmake ..
make
./server          # в одном терминале
./client          # в другом, клиентов можно запустить несколько
```
